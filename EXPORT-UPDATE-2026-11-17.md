# Экспорт по университетскому образцу

Word-экспорт переработан по предоставленному файлу «Үлгі.docx» и визуальным замечаниям в видео «Силлабусты тексеру». В аудиодорожке видео звук отсутствует.

Изменения:
- Титульный лист с исходным логотипом университета и расположением реквизитов по образцу.
- A4, поля и колонтитулы исходного образца; титульный лист без номера, следующие страницы с номером справа и обозначением формы слева.
- Основной текст Times New Roman 14; таблицы используют размеры из образца, без произвольного уменьшения всего документа.
- Раздельные контакты лектора и преподавателя практики. Добавлены поля кабинета, часов консультаций и электронной почты преподавателя практики, формы обучения и должности утверждающего.
- Таблицы пререквизитов, литературы, компетенций, критериев и подписей оформлены по образцу; заголовки повторяются при переносе таблиц.
- Таблица оценивания выводится в 19 столбцах: недели 1–15, отдельная строка экзамена и объединённые итоги. Внутренние данные по-прежнему хранятся в прежнем формате из 20 столбцов.
- Формула оценивания расположена после таблицы критериев. Дополнительные пояснения из отмеченных в видео разделов не выводятся в стандартный Word, но сохраняются в проекте. В редакторе это обозначено.
- Рукописная подпись из образца не копируется. В новые документы входят только имена, введённые пользователем; утверждение и подписание выполняются отдельно.

Для экспорта используйте «Word» в меню выгрузки. Настройки экранного предпросмотра и браузерной печати не изменяют утверждённое оформление Word. Браузерная печать/PDF использует прежний экранный макет.

Исходный образец не изменялся. Шаблон экспорта хранится в data/export-template.json; исходный файл с подписью и видео в распространяемый проект не включены. Сопоставление выполнено с конкретным предоставленным образцом, а не с отдельно указанным номером ГОСТ.

Для запуска распакуйте архив, откройте папку «Satbayev-Syllabus-updated Github/Satbayev-Syllabus final» и запустите START_WINDOWS.bat. Требуется Python 3. При обновлении существующей установки сохраните её папку runtime — там находятся аккаунты, настройки и силлабусы. Архив содержит исходный код и шаблоны, но не личную базу данных и не ключи API.
