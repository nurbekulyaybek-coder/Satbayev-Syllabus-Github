# Satbayev Syllabus Studio

Приложение для создания и редактирования силлабусов. Поддерживает казахский, русский и английский языки, автоматический подсчёт баллов и экспорт документов.

## Запуск на компьютере

1. Установите **Python 3.10 или новее**.
2. На странице GitHub нажмите **Code → Download ZIP**.
3. Распакуйте архив.
4. На Windows запустите **START_WINDOWS.bat**.
5. Откройте в браузере **[http://localhost:8000](http://localhost:8000)**.
6. Введите логин и пароль, полученные у администратора.
7. Начальные данные для входа:
   | Аккаунт       | Логин   | Пароль               |
   | ------------- | ------- | -------------------- |
   | Администратор | `admin` | `SatbayevAdmin#2026` |
   | Преподаватель | `user`  | `Teacher#2026`       |

Для macOS и Linux выполните в папке проекта:

```bash
python3 server.py --open
```

Пока работаете с приложением, оставляйте окно сервера открытым.

## Как пользоваться

1. Заполните основные сведения: институт, кафедру, образовательную программу и дисциплину.
2. Выберите нужный раздел в панели **«ҚҰЖАТ ҚҰРЫЛЫМЫ»**.
3. Редактируйте текст слева или непосредственно в документе справа.
4. Кнопка **+** добавляет новый абзац. В текстовом поле доступны копирование и вставка.
5. В таблице баллов вводите числа от **0 до 100** — итоги рассчитываются автоматически.
6. Изменения сохраняются автоматически. Для сохранения вручную нажмите **«Сақтау»**.

Готовый силлабус можно скачать в **Word**, сохранить в **PDF** через «Баспа / PDF» или экспортировать в **HTML/JSON** через меню «Экспорт».

## Доступ преподавателям

Для совместной работы администратор запускает приложение на общем сервере, создаёт отдельные аккаунты и выдаёт преподавателям ссылку, логин и пароль. У каждого аккаунта свой силлабус.

При таком доступе преподавателю достаточно браузера — устанавливать Python не нужно.

**GitHub хранит исходный код. Для работы приложения требуется запущенный Python-сервер.**

## Сохранность данных

Папка `runtime` содержит документы, аккаунты и настройки. Сохраняйте её при обновлении проекта и не загружайте в публичный репозиторий вместе с API-ключами и личными данными.
