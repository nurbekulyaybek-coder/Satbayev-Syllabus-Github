# Satbayev Syllabus Studio v4

Ортақ сайт / общий сайт с аккаунтами admin/user. Силлабус, интерфейс, Word и PDF: қазақша, русский, English. Добавлен контекстный ИИ-чат.

## Запуск на Windows

1. Распакуйте весь ZIP в обычную папку.
2. Нужен **Python 3.10 или новее**. Сторонние Python-пакеты не нужны.
3. Дважды нажмите **START_WINDOWS.bat**. Откроется браузер: **http://localhost:8000**.
4. Оставьте окно сервера открытым во время работы.

Вручную: `py server.py --open`. Linux/macOS: `python3 server.py --open`.

Открытие `index.html` двойным щелчком показывает инструкцию запуска. Настоящие аккаунты и общее сохранение работают через сервер, а не через файл `file://`.

## Начальные аккаунты

| Роль | Логин | Пароль |
|---|---|---|
| Администратор | `admin` | `SatbayevAdmin#2026` |
| Преподаватель | `user` | `Teacher#2026` |

Пароль меняется через кнопку аккаунта в верхней панели. Admin создаёт дополнительные аккаунты, назначает роли, отключает доступ и сбрасывает пароли в разделе «Аккаунттар / Аккаунты».

Начальные пароли можно задать переменными `SYLLABUS_ADMIN_PASSWORD` и `SYLLABUS_USER_PASSWORD` **до первого запуска**. После создания базы изменение этих переменных существующие пароли не меняет.

## Один адрес для всех

Сервер по умолчанию слушает порт 8000 на всех сетевых интерфейсах. В одной локальной сети другие компьютеры открывают `http://IP-КОМПЬЮТЕРА-С-СЕРВЕРОМ:8000`. Windows может запросить разрешение сетевого доступа. У всех должен быть один сервер и одна база, а не отдельная копия сервера на каждом компьютере.

Это серверная версия для запуска у вас; публичного интернет-адреса в архиве нет. Для доступа через интернет сервер размещается на постоянном хосте за HTTPS reverse proxy; при HTTPS задайте `SYLLABUS_SECURE_COOKIE=1`.

## Права и сохранение

| Объект | user | admin |
|---|---|---|
| Собственный текст, план, числовые баллы | Изменение | Изменение |
| ФИО директора, заведующего, согласующие | Чтение | Изменение |
| Связи институт → кафедра → БББ → пән | Выбор из назначенного списка | Настройка связей |
| Политики, шкала, критерии и оформление | Чтение | Изменение |
| Университет, заголовки и подписи | Закреплены | Закреплены |
| Аккаунты и полный проект через сайт | Недоступны | Управление / скачивание |

Права проверяются **на сервере** при каждом сохранении. Изменение кнопок или роли в DevTools не даёт доступа.

У каждого аккаунта собственный силлабус. Директор, заведующие, связи, шаблонные политики и справочники — общие настройки. После изменения администратором другие преподаватели получают их при следующем открытии или через «Обновить с сервера».

Сохранение автоматическое после ввода; кнопка «Сақтау / Сохранить» запускает его сразу. Статус показывает результат. При конфликте версий сервер возвращает сообщение и не перезаписывает более новые данные. Перед обновлением можно скачать Word/JSON-копию своих изменений.

Данные находятся в **runtime/syllabus.sqlite3** рядом с сервером. Для резервной копии остановите сервер и скопируйте папку runtime. База и сессии не входят в скачиваемый исходный проект.

## Как настроить зависимые списки

Admin → «Анықтамалық / Справочник» → выберите институт → откройте нужную кафедру → отметьте её программы. Затем в блоке дисциплин задайте код, название и программы, которым дисциплина доступна.

В начальных данных подтверждены связи кафедры кибербезопасности и четыре программы кафедры энергетики. Для остальных кафедр список программ изначально пуст: страница Univision **не содержит полной привязки кафедра → программа**, и приложение не выдумывает такие связи. В общем справочнике сохранены 227 кодированных записей программ для назначения администратором.

При смене института кафедра, программа и дисциплина очищаются. При смене кафедры очищаются программа и дисциплина. В каждом списке появляются только связанные значения. В чужую кафедру или программу нельзя попасть и прямым запросом к API.

## Даты, шаблон и баллы

- Компактный календарь с месяцем и годом, корректными днями и високосными годами. Диапазон дат: 2020–2100.
- Год титула: до 2100. Учебные годы: до 2099–2100.
- Дата утверждения, дата протокола и номер задаются на титуле. Заголовки и повторяющиеся реквизиты берутся из одного источника.
- `{{course}}`, `{{code}}`, `{{program}}`, `{{year}}`, `{{department}}` в тексте — ссылки на титул. На экран и в Word выводятся значения. Строки с такими ссылками в документе закреплены; при необходимости редактируйте окружающий текст в редакторе, сохраняя ссылки.
- В графике №9 числовые клетки принимают 0–100, максимум два десятичных знака. Итог справа — сумма недель и отдельной колонки экзамена. Колонка «максимум» в эту сумму не входит. Итоги и номера строк не вводятся вручную.
- Экзамен имеет отдельную колонку, чтобы не приписывать его ошибочно к 15-й учебной неделе.
- Зелёные/жёлтые индикаторы показывают заполнение разделов и колонок. Ноль — допустимое заполненное число.
- При выборе раздела лента документа прокручивается к нему. При редактировании текущая позиция сохраняется.

## Экспорт

Word — настоящий редактируемый `.docx`. PDF — через браузер: A4, масштаб 100%, поля «Нет», колонтитулы браузера выключены. HTML — отдельный снимок документа для просмотра/печати, без аккаунтов и серверного редактирования. JSON — перенос данных; при импорте user не получает возможность заменить закрытые настройки.

## Структура проекта

- `server.py`: HTTP API, SQLite, сессии, scrypt-хеши паролей, роли, валидация, версии сохранения.
- `src/app.js`: основной интерфейс и сборочные вставки.
- `src/features.js`: базовые функции редактора.
- `src/v3.js`: роли, календарь, связанные списки, калькулятор, индикаторы и API.
- `src/inline-editor.js`: страницы и редактирование документа.
- `src/word-export.js`: DOCX/ZIP без внешних зависимостей.
- `src/styles.css`, `src/shell.html`: внешний вид и HTML.
- `data/initial-state.json`: начальные данные и явные связи.
- `build.py`: сборка HTML из исходников.
- `tests/`: проверки серверных прав, логики UI и DOCX.

Изменение исходников: `python build.py`, затем перезапустите сервер и обновите браузер. База существующих пользователей при пересборке не удаляется. Изменения в исходном JSON не заменяют текущую базу: используйте админ-панель или отдельную новую тестовую базу.

Проект основан на присланном образце «ҚазҰТЗУ 703-08 Ү. Силлабус»; это учебный проект, а не официальное подтверждение соответствия университета.


## Полный перевод силлабуса

Кнопка ҚАЗ / РУС / ENG переключает титул, 13 разделов, таблицы, подписи, повторяющиеся реквизиты и экспорт Word/PDF. Для исходного шаблона переводы уже включены: интернет не требуется. Числа и коды сохраняются, ФИО и оригинальные названия изданий не переводятся.

Изменённые преподавателем тексты и новые названия, отсутствующие в словаре, переводятся через ИИ. Для этого нужен подключённый API. При ошибке переключение отменяется целиком, исходный документ сохраняется. Переводы кешируются в базе. Текст, числа, формулировки политики и перевод названий необходимо проверить перед утверждением.

## Подключение ИИ

1. Создайте свой API-ключ OpenAI с доступом к модели и балансом API.
2. На компьютере сервера запустите **SETUP_AI_WINDOWS.bat** (или `python3 configure_ai.py`). Введите ключ в скрытом поле консоли; модель по умолчанию — `gpt-4.1-mini`.
3. Перезапустите сервер через START_WINDOWS.bat. В окне чата должен появиться статус подключения.

Альтернатива: переменные окружения `OPENAI_API_KEY` и, по желанию, `OPENAI_MODEL`. Ключ сохраняется только в `runtime/ai-config.json` на сервере. В браузер, HTML, Word и ZIP исходного проекта он не включается. Не передавайте свою папку runtime другим пользователям вместе с исходниками.

Ключ в проект **не включён**. Без ключа есть окно, контекст и готовые запросы, но генерация и перевод произвольного текста не выполняются. Подписка ChatGPT не заменяет баланс API. Запросы выполняются с `store:false`, но данные отправляются провайдеру ИИ; не включайте в запросы персональные данные студентов.

### Работа с чатом

- Нажмите **✦ ИИ-помощник** справа внизу.
- Нажмите на текст силлабуса или выделите фрагмент — рядом появится маленькая **✦**. Она откроет чат с выбранным контекстом.
- Готовые запросы: темы занятий, практическая работа, результаты обучения, переработка текста, тесты. Нажатие подставляет запрос; отправка выполняется отдельной кнопкой.
- Ответ выдаётся на выбранном языке силлабуса. Его можно скопировать, добавить к выбранной строке или заменить выделенный фрагмент. Применение выполняется только по нажатию и с учётом прав admin/user. Числовые ячейки и закреплённые поля защищены.
- Если исходный фрагмент изменился или язык переключился, применение старого ответа блокируется. Чат очищается при выходе из аккаунта и не сохраняется между перезапусками страницы.

Контекст включает дисциплину, программу, раздел, выбранный фрагмент и последние сообщения чата. Сервер ограничивает запросы: 12 в минуту на аккаунт и до 3 одновременных обращений. При ошибке API показано сообщение, выдуманные ответы не подставляются.

- Проверки: `python3 tests/server.test.py`, `python3 tests/languages-ai.test.py`, `node tests/ui-logic.test.cjs`, `node tests/export.test.cjs` (после сборки).

Проверены роли, сохранение и переключение трёх языков, структура DOCX и отправка контекста ИИ. Интеграционный тест ИИ использует локальный тестовый HTTP-сервер; живой запрос к OpenAI не выполнялся, поскольку API-ключ не предоставлен. Этот тестовый сервер не используется приложением. Браузерная визуальная проверка в текущей среде недоступна.

## Правки интерфейса · 30.10.2026

- Структура документа автоматически выделяет раздел при прокрутке документа и удерживает выбранный пункт в видимой части списка. Нажатие пункта по-прежнему прокручивает документ к разделу.
- Кнопка «←» рядом со счётчиком `00 / 15` скрывает редактор. Кнопка «→» над документом возвращает его.
- В разделе 9 баллы вводятся непосредственно в ячейках таблицы, без диалогового окна. Доступны целые числа 0–100; на телефоне запрашивается цифровая клавиатура. Расчётные итоги защищены от редактирования. Суммы строк, столбцов и общий балл обновляются сразу. Если общий балл превышает 100, он подсвечивается: значение не обрезается и не скрывает ошибку распределения.
- JSON и HTML находятся в выпадающем меню «Экспорт». Word, сохранение и печать остаются отдельными кнопками.

Запуск на Windows: распакуйте архив целиком и запустите `START_WINDOWS.bat`. Если предыдущая версия сервера работает, закройте её и запустите обновлённую. Откройте `http://localhost:8000`, при необходимости обновите страницу через Ctrl+F5.

Проверки: `python build.py`, `node tests/ui-logic.test.cjs`, `node tests/export.test.cjs`; серверные тесты запускаются файлами `tests/server.test.py` и `tests/languages-ai.test.py` на отдельной тестовой базе. Не запускайте серверные тесты на рабочей базе. Дополнительные проверки DOM: установите jsdom для тестирования (`npm install --no-save jsdom`) и выполните `node tests/ux-dom.test.cjs`. Приложению Node.js и jsdom не требуются.


## Текст и абзацы · 31.10.2026

- При очистке «Бөлім мәтіні» остаётся пустой редактируемый абзац в документе. Повторная загрузка страницы для восстановления поля не нужна.
- Плюс в поле документа добавляет пустой абзац под соответствующим абзацем. Плюс под текстовым полем редактора добавляет абзац под строкой с курсором. Новая строка сразу получает фокус.
- В правом верхнем углу текстового поля: вставка из буфера обмена (в текущую позицию или вместо выделения) и копирование всего текста поля. Если браузер блокирует доступ к буферу, появится подсказка воспользоваться Ctrl+V или Ctrl+C.
- Добавленные пустые абзацы сохраняются на сервере и в Word/HTML. Подсказки и кнопки «+» не включаются в документ при экспорте и печати.

**Обновление без потери данных:** остановите сервер, распакуйте обновлённый архив в отдельную папку, перенесите в неё папку `runtime` из вашей текущей рабочей версии с заменой файлов. Именно ваша папка `runtime` содержит актуальные документы, аккаунты и настройки. Затем запустите `START_WINDOWS.bat` из новой папки и обновите браузер через Ctrl+F5. Старую папку сохраните до проверки обновления.

Дополнительная проверка: `node tests/text-tools.test.cjs` (для теста требуется jsdom). Тестируется пустое поле, добавление в середину текста, ввод с Enter, копирование/вставка, сохранение/загрузка и HTML без элементов редактора.
