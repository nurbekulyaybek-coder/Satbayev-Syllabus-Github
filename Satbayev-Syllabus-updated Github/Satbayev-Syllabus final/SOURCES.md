## Ограничения исходных данных

- Univision смешивает исторические и современные названия. Они сохранены с отметкой источника. Admin должен сверить используемую структуру с действующими документами.
- Страница факультетов устанавливает принадлежность кафедр институтам, но не устанавливает полную принадлежность программ конкретным кафедрам. В v3 нет автоматического назначения «всех программ всем кафедрам».
- Начальные кафедра→программа связи заданы для Киберқауіпсіздік (6B06301, 7M06301, 8D06301) и Энергетика (6B07101, 6B07122, 6B07127, 6B07128). Остальные связи назначаются администратором в интерфейсе по утверждённым данным.
- В исходном файле есть один предмет CSE5491; его связь с 6B06301 задана. Другие предметы и их связи добавляет admin. Univision не содержит полного каталога отдельных дисциплин.
- Директор и заведующий из пользовательского DOCX сохранены как исходные данные, а не как подтверждение того, кто занимает должность сейчас. Некоторые официальные страницы во время обновления возвращали ошибку доступа.
- Выбор других университетов удалён. Система предназначена только для Satbayev University.
- Тексты исходного курса не пересочинялись: отмеченное ранее несоответствие целей теме курса остаётся предметом содержательной проверки преподавателем.
- Оформление основано на образце пользователя и форме 703-08; официальная сертификация соответствия не проводилась.
